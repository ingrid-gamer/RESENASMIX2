# Manual de usuario — RESENASMIX2

## 1. Ingreso al sitio
Abra la dirección web entregada por el equipo. En la página principal encontrará accesos al catálogo, categorías, ofertas y cuenta de usuario.

## 2. Crear una cuenta
1. Seleccione **Registrarse**.
2. Complete nombre, nombre de usuario, correo y contraseña.
3. Envíe el formulario.
4. Si el nombre de usuario ya existe, utilice otro.

## 3. Iniciar sesión
1. Seleccione **Iniciar sesión**.
2. Ingrese usuario y contraseña.
3. Presione **Entrar**. Si las credenciales son correctas, se habilitarán las funciones asociadas a su cuenta.

## 4. Buscar videojuegos
1. Abra **Videojuegos**.
2. Escriba el título en el buscador o explore el catálogo.
3. Seleccione un videojuego para consultar su detalle.

## 5. Publicar una reseña
1. Inicie sesión.
2. Abra el videojuego que desea evaluar.
3. Ingrese una calificación y un comentario.
4. Envíe la reseña y compruebe que aparezca en la sección correspondiente.

## 6. Carrito y checkout
1. En el catálogo, seleccione **Agregar** en el videojuego deseado.
2. Abra **Carrito** para revisar los productos.
3. Elimine productos o vacíe el carrito si es necesario.
4. Seleccione **Continuar al checkout**.
5. Complete nombre, correo, dirección y tipo de entrega.
6. Confirme la operación.

**Advertencia:** el flujo registra una compra de demostración en la base de datos cuando el frontend está conectado al backend y el usuario inició sesión. En modo local solo se guarda en el navegador. No equivale a un pago real.

## 7. Cerrar sesión
Abra el menú de cuenta y seleccione **Cerrar sesión**. Las páginas protegidas solicitarán autenticación cuando corresponda.

## 8. Problemas frecuentes
- **No puedo iniciar sesión:** revise usuario y contraseña.
- **No aparecen videojuegos:** compruebe la conexión y vuelva a cargar el catálogo.
- **No puedo publicar una reseña:** inicie sesión y verifique que el formulario esté completo.
- **El sitio no responde:** comuníquese con el equipo administrador e indique la hora y pantalla donde ocurrió el problema.
